# BermaroRueckhol – Plenty-Plugin

Bindet das Skript des BERMARO Rückhol-Systems in einen Ceres-Shop ein und legt im Cookie-Banner den Eintrag „Rückhol-System“ (Gruppe Tracking) an.

Dieses Repository enthält **nur** den Einbindungs-Code (ein Skript-Tag und den Cookie-Banner-Eintrag). Es enthält keine Kundendaten, keine Passwörter und keine Zugangsschlüssel. Server-Adresse und Shop-ID werden in Plenty in der Plugin-Konfiguration eingetragen.
