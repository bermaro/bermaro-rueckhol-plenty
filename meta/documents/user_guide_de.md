# BERMARO Rückhol-System – Plenty-Plugin

1. Plugin über Git ins Plugin-Set einbinden.
2. Konfiguration: Server-Adresse und Shop-ID eintragen.
3. Container-Verknüpfung: „Rückhol-Skript“ → „Ceres::Script loader: After scripts loaded“.
4. Plugin-Set speichern und bereitstellen.
5. Im Cookie-Banner erscheint unter „Tracking“ der Eintrag „Rückhol-System“.
